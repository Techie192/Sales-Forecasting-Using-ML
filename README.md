# Project Overview

Sales Forecasting Using ML is a predictive analytics project focused on analyzing historical sales data and developing a machine learning model to forecast future sales trends.

The project applies data preprocessing, exploratory data analysis, feature engineering, and regression techniques to identify sales patterns and generate data-driven predictions.

---

# Objectives

The main objectives of this project are:

- Analyze historical sales data to identify trends and patterns
- Clean and preprocess sales datasets
- Perform exploratory data analysis
- Create meaningful features for prediction
- Build a machine learning regression model
- Evaluate model performance
- Visualize actual and predicted sales results

# Dataset

**Dataset Used:** Superstore Sales Dataset

The dataset contains historical sales transactions including:

- Order Date
- Sales
- Quantity
- Discount
- Category
- Region
- Customer Segment

---

# Exploratory Data Analysis

Performed analysis to understand historical sales patterns:

- Monthly sales trend analysis
- Category-wise sales performance
- Regional sales analysis
- Sales pattern identification

---

# Data Preprocessing

Performed preprocessing steps:

- Missing value analysis
- Duplicate removal
- Date conversion
- Feature extraction
- Categorical encoding

Created features:

```
Year
Month
Quarter
```

---

# Machine Learning Model

## Random Forest Regression

A Random Forest Regression model was used to predict future sales values based on historical data.

The model learns relationships between different features and sales performance to generate predictions.

---

# Model Evaluation

The model performance was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
